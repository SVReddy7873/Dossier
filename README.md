# Dossier — Interactive 3D Portfolio

An interactive 3D personal portfolio website for **M. Anjani Sai Vivek Reddy**, showcasing his profile as a **Computer Science Engineer & AI/ML Developer**.

🌐 **Live Portfolio:** https://svreddy7873.github.io/Dossier/

## ✨ Features

* 🎨 Interactive 3D portfolio experience
* 🪪 Professional profile presentation
* 🖱️ Interactive 3D navigation
* 🃏 Expandable profile and portfolio cards
* 🔄 Drag/scroll interaction for the 3D view
* 💻 Responsive web experience
* 🚀 Hosted using GitHub Pages

## 👨‍💻 About

**M. Anjani Sai Vivek Reddy** is a Computer Science Engineer and AI/ML Developer. This portfolio is designed to provide an interactive and visually engaging way to explore his professional profile, skills, projects, and other career-related information.

## 🖥️ Portfolio Experience

The website starts with an interactive **3D light-plate presentation**. Users can toss the coin to launch the experience and interact with the 3D interface.

The portfolio supports:

* Scrolling and dragging to rotate the 3D view
* Clicking cards to expand their details
* Navigating between different portfolio sections
